# Контракт бібліотеки PolynomialLib (Варіант 3, Студент Б)

**Версія API:** 1.0
**Бінарний файл:** `PolynomialLib.dll`
**Імпортна бібліотека:** `PolynomialLib.lib`
**Заголовковий файл:** `PolynomialLib.h`

## Представлення полінома
Поліном представляється масивом коефіцієнтів `double* coeffs`, де
`coeffs[i]` — коефіцієнт при `x^i`. Розмір масиву `size` = ступінь
полінома + 1.

Приклад: поліном `3x^2 + 2x + 1` → `coeffs = {1.0, 2.0, 3.0}`, `size = 3`.

## Функції

### `double* polyAdd(const double* a, int sizeA, const double* b, int sizeB, int* outSize)`
- **Призначення:** додавання двох поліномів `a + b`.
- **Параметри:** `a`, `b` — масиви коефіцієнтів; `sizeA`, `sizeB` — їх розміри; `outSize` — вихідний параметр, куди записується розмір результату.
- **Обмеження:** `a != nullptr`, `b != nullptr`, `sizeA > 0`, `sizeB > 0`, `outSize != nullptr`.
- **Результат:** новий масив розміру `max(sizeA, sizeB)`.
- **Помилки:** при некоректних параметрах повертає `nullptr` і встановлює `*outSize = 0`.
- **Керування пам'яттю:** результат виділяється бібліотекою (`new[]`). Користувач ОБОВ'ЯЗКОВО звільняє його через `polyFreeArray()`.

### `double* polyMultiply(const double* a, int sizeA, const double* b, int sizeB, int* outSize)`
- **Призначення:** множення двох поліномів `a * b`.
- **Результат:** новий масив розміру `sizeA + sizeB - 1`.
- **Обмеження та помилки:** аналогічно `polyAdd`.
- **Керування пам'яттю:** так само, звільняти через `polyFreeArray()`.

### `double polyEvaluate(const double* coeffs, int size, double x)`
- **Призначення:** обчислення значення полінома в точці `x` (схема Горнера).
- **Обмеження:** якщо `coeffs == nullptr` або `size <= 0`, повертає `0.0`.
- **Побічні ефекти:** немає, пам'ять не виділяється.

### `double* polyDerivative(const double* coeffs, int size, int* outSize)`
- **Призначення:** похідна полінома.
- **Результат:** новий масив розміру `size - 1` (якщо `size == 1` — результат `{0.0}` розміру 1).
- **Обмеження та помилки:** аналогічно `polyAdd`.
- **Керування пам'яттю:** звільняти через `polyFreeArray()`.

### `double* polyIntegral(const double* coeffs, int size, double constant, int* outSize)`
- **Призначення:** невизначений інтеграл (первісна) полінома зі сталою інтегрування `constant`.
- **Результат:** новий масив розміру `size + 1`.
- **Обмеження та помилки:** аналогічно `polyAdd`.
- **Керування пам'яттю:** звільняти через `polyFreeArray()`.

### `void polyFreeArray(double* array)`
- **Призначення:** звільнення пам'яті, виділеної будь-якою з функцій вище.
- **Обмеження:** безпечно викликати з `array == nullptr` (нічого не відбувається).
- **ВАЖЛИВО:** не можна звільняти результат через `free()` або `delete[]` напряму — лише через цю функцію, оскільки пам'ять виділялася всередині DLL оператором `new[]`.

## Загальні правила
- Усі функції мають C-зв'язування (`extern "C"`), декорування імен (name mangling) відсутнє.
- Жодна функція не модифікує вхідні масиви (вони `const`).
- Версія бінарного файлу: 1.0. Сумісність API зберігається, доки сигнатури функцій не змінюються.
